# Template — Mount-Point (Storage Class)

<<~ ahu #intent >>

## Intent

A mount-point meme names **where a module seats on an entity** and the contract that seating implies. The same module behaves differently depending on which mount-point holds it. Contracts come from the canonical Vastlands Guidebook / SDM rules; this meme addresses them, it does not invent new rules.

<<~/ahu >>

<<~ ahu #required-shape >>

## Required Shape

```text
#contract    what this mount-point is; capacity rule; what it accepts
#activation  how a module seated here activates differently
#cost        Life / Ability-Point / resource cost while seated here
#failure     how a module seated here fails; what failure does to the host
#removal     how a module leaves; what removal costs or breaks
#overflow    what happens past capacity (e.g. spill to Burden, or buy more)
#aftermath   open questions, design-space flags
```

<<~/ahu >>

<<~ ahu #writing-law >>

## Writing Law

- State the capacity rule plainly. Where it is canonical (Trait 7+Thought, Item 7+Strength, Burden 20/−1), cite the book and hold a confident register. Where it is design-space (the Site capacity economy), say so and boot at a low register.
- Do not duplicate component or module text. A mount-point describes the *seat*, not the *thing seated*.
- Name counterplay: how an opponent disables, dispels, or strips a seated module.
