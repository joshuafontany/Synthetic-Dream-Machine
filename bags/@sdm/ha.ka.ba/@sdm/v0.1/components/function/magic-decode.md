# Magic Decode

<<~ ahu #definition >>

## Definition

Decoding a magical inscription or interface layer into active, readable meaning — the core function of Read Magic.

<<~/ahu >>

<<~ ahu #activation >>

## Activation

Turns opaque marks into usable instruction: one inscription per activation at base P. Overcharge reads through veils or decodes more at once.

<<~/ahu >>

<<~ ahu #interaction >>

## Interaction

Depends on `domain/divination`; pairs with `function/archive` for the handshake that fetches an inscription's stored meaning. A `veil` or `spoof` raises its effective P or feeds it false meaning.
