# Sustained

<<~ ahu #definition >>

## Definition

A canonical duration hook (the `focus` family): the Power persists only while the practitioner sustains concentration. Distraction, damage, or competing action deactivates it.

<<~/ahu >>

<<~ ahu #activation >>

## Activation

Modifies duration, not effect. The Power runs as long as attention holds; a save or interruption can drop it. Only so many sustained Powers run at once.

<<~/ahu >>

<<~ ahu #interaction >>

## Interaction

Common on `function/barrier`, `function/ward`, `function/cargo`, and `domain/stuckforce`. Trades against `hook/imbued` (which holds via locked Life rather than attention).
