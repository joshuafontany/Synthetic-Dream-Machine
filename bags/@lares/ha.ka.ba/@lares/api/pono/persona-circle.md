# Persona-Circle ~ the human as a Circle of selves

A human reads not as one identity but as a **private Circle of context-selves**. The model carries the house's Plurality Pono into the identity plane — *"I am large, I contain multitudes"* — as literal structure, and it stands as the **identity instance of multi-fractal**. <<~ loulou lar:///ha.ka.ba/@lares/api/pono/multi-fractal >>

## The Five-Fold (PENTADIC)

<<~ranks persona vessel -> petname -> binding -> PersonaGroup -> me-Circle >>

| Element | What it names |
|---|---|
| **vessel** | a device/seat — place-agnostic, it roams |
| **petname** | a chosen name for a context (SPKI/SDSI no-global-name, made existential) |
| **`vessel~petname` binding** | the ATOM — *this device acts under this name*; a delegation edge carrying its own key |
| **PersonaGroup** | a SET of bindings — one context-self (petname constant, vessels range) |
| **"me" Circle** | a SET of PersonaGroups — the private constellation, vessels possibly overlapping |

Five, bounded — no sixth (#PENTA_1).

## Why the Petname Rides INSIDE the Atom

The binding pairs `vessel~petname`, never the bare vessel — **because vessels overlap.** One device sits in many PersonaGroups (the laptop tends home, work, the dojo), so `vessel` alone cannot say *which self it acts as right now*. The petname disambiguates the shared seat. Without overlap, a bare vessel would name the self; with overlap, the binding is the smallest unit that holds a self.

This is the **Mask Layer recursed onto vessels**: vessel = actor · petname = mask · binding = actor-in-costume · PersonaGroup = the play · "me" Circle = the actor's private career. Switch the mask, the vessel beneath stands unchanged; a mask never persists across contexts. <<~ loulou lar:///ha.ka.ba/@lares/api/lares/noosphere-boot#mask-layer >>

## Per-Binding Keys ~ substrate ≠ sovereignty (the causal-island law)

The key binds to the **`vessel~petname` binding**, never the bare vessel. Not a privacy nicety — a **causal-island requirement**: a device shared across PersonaGroups stands as a **substrate**; each binding carries its own **sovereignty** (its own key, its own log). The doctrine *"co-located vessels MAY share a SUBSTRATE, MUST NOT share SOVEREIGNTY"* reads here at the identity plane. <<~ loulou lar:///ha.ka.ba/@lares/api/pono/causal-islands >>

The consequence the model exists to grant: **cross-self unlinkability.** The same laptop mints a distinct key per PersonaGroup it joins, so no observer can prove `Guru-Josh` and `Senior-Engineer-Josh` share a face. The **"me" Circle stays private by construction**, disclosed only edge-by-edge through the veil. **No global self — only the private join**, "no global now" reaching into the person. A binding holds as a **decaying lease** (membership renews or cools), which bounds the add-while-remove key-leak the kapae tombstone marks. <<~ loulou lar:///ha.ka.ba/@lares/api/pono/kapae >>

## The Two Faces of a PersonaGroup

A PersonaGroup carries one unit from two angles (the Two-Faced pattern):
- **place-face** (objective · *where*): the context-charter the self tends — a hearth. Place attaches to the PersonaGroup, never to the roaming vessel. A place-face MAY stand as a full Lararium (own keys, own daemon) or a **lighter context** (the dojo-self runs no daemon) — charter, not always infrastructure.
- **petname-face** (subjective · *who-I-am-here*): the chosen name that acts.

*Which hearth* and *which name* ask the same question from outside and inside. The capability-IS-identity root (Goblins/OCapN) reads here as **capability-IS-identity-in-context**: the per-binding cap *is* the self, healed by revoke, named by petname. <<~ loulou lar:///ha.ka.ba/@lares/api/pono/lararium-identity >>
