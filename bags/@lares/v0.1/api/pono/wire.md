# Wire — the reified edge

A relation rich enough to *do* something — carry a value, route a message, gate execution, hold a constraint, watch a surface — reifies as its **own entity** (has-stack clause 7): a `lar:` addressed record with `from` and `to` fields, wearing its semantics as stack components. The canvas renders wire entities; the messaging plane compiles them; replicas merge them as records.

A wire that merely *points* stays a `loulou`; embedding stays `aka`/`kahea`; composition stays the tags stack. The wire begins where adjacency ends.

## Wire Law

1. **One wire, one entity.** A wire exists as one `lar:` addressed record carrying `from` and `to` (each a `lar:` URI or `URI#socket`). It MUST NOT exist as an attribute on a line of prose — the corpus-wide attribute-edge form retired 2026-06-12.
2. **Semantics worn, never typed-in-place.** A wire wears its family as a stack component — `wires/dataflow`, `wires/message`, `wires/control`, `wires/constraint`, `wires/observe` ride as *examples, not an enum* (has-stack clause 4: open minting, ladder-judged). The family definition meme carries the meaning; the wire record carries only endpoints and fields.
3. **The four concerns stay independent** (inherited whole from the prior edge law): `traversal` (how a query moves) · `propagation` (how invalidation fires) · arity (family-declared, has-stack clause 5) · lifecycle. They ride as **fields** on the wire record and MUST NOT collapse into each other.
4. **Lifecycle = template · instance · trace.** A template wire carries slots and defaults; an instance binds real endpoints; a **trace** records a firing, failure, or event — each its own entity, so the event history merges and federates like any record.
5. **Directed, acyclic per family.** One wire carries one arc. Reciprocal pressure uses two wires. Cycles within a family read as degraded structure.
6. **Wires hold grants.** As entities, wires wear kapu and capability components like any carrier — a message route can require an operator mint; an attribute on a line never could. Authority = what the wire holds.
7. **The engine vends liveness, wires declare intent.** A `wires/message` instance compiles into the reaction plane (`ReactionBinding`; engine-vended `listenable`s — `verse-event-lattice` law unchanged). The wire = the authored, addressable declaration; the binding = the engine's live subscription. Events ride wires and lifetime edges — never a global bus.
8. **Canvas renders, never infers.** The explicit wire entity precedes its spatial form (graph-primacy, `wikispace-canvasspace-ontology`); proximity creates nothing. Wire view-state (path, routing, label placement) lives in view-state entities, never on the wire record.
