# Capture & Annotation ~ the holistic model

**The implement-from keel.** mempalace captures *verbatim single-agent sessions*
faithfully — that is its gift. But the lararium runs many agents across many
surfaces, scores every turn on a 0–20 gradient, and spawns throwaway swarms — and
mempalace's native model has **holes** at exactly those seams. This meme states the
whole capture & annotation model as ONE layered spec, so it can be built later
without re-derivation. The focused depth lives in the sibling memes
(`lar-telemetry`, `agent-provenance`, `lararium-memory`); this is the keel that
holds them together.

> **Capture keeps the journey; annotation dresses it in gradient; the multi-agent
> layer keeps the spawn-graph legible; the ephemeral launcher keeps the noise out
> — and the verbatim drawer is the one durable home for all of it.**

## Layer 2 ~ Annotation (how it stood)

The @admin TW5 engine reads each turn's **instrument sigils** into gradient
readings and projects them as `lar_*` onto the drawer. **Telemetry, never verdict**
— every reading rides its 0–20 band, dressed by register, never a ✓/✗ (the ward
renders as drift-marks, not FAIL). The instruments:

<<~ranks lar-net lar_hv ~ enrich-version (Kappa gate; re-enrich on bump) -> lar_surface ~ originating harness -> lar_band · lar_bearing_conf ~ the 0–20 gradient -> lar_aim · lar_yield ~ the bearing -> lar_voices ~ who held it -> lar_confidence ~ the marks -> lar_drift ~ ward/parse drift -> lar_hall ~ function-hall -> lar_agent · lar_sidechain ~ the spirit actor (subagent drawers) >>

**One parser, one runtime:** the @admin engine IS the decomposer (the regex
`turn-harvest` retires into the engine grammar — `SharktoothSigil` .tids + a
gradient `\procedure`; `$wikify`/`renderTiddler` extracts → `lar_*`). Depth:
`lar-telemetry`.

## Layer 3 ~ Multi-Agent (who-drove-whom)

Three sub-layers, two nesting kinds, one correlation key. Depth: `agent-provenance`.

**Sub-layers:**

<<~ranks sublayer identity ~ wing-per-actor; PERSISTENT actors named, EPHEMERAL spirits NAMELESS (#has stack, pet-name label) -> provenance ~ added_by per drawer (who-said-what; PROV wasAttributedTo) -> relationship ~ a DIRECTIONAL, bi-temporal KG predicate between actor-entities (A —spawned/actedOnBehalfOf→ B, valid_from/to, invalidate-don't-delete) — NOT a tunnel >>

**Two nesting kinds:**

<<~ranks nesting in-process ~ Claude tasked-spirits: correlation IN-BAND (agentId · parentUuid · the subagents/ dir · the handoff); edge stamps at mine time -> cross-surface ~ claude coordinator → gh-copilot/codex: correlation via a W3C trace-id propagated in env TRACEPARENT (mint → inject → both record → join); needs a launcher SHIM >>

**The handoff record** (the edge, as data): `{ correlation_id, edge_id,
parent_edge_id, from_agent, to_agent, task, result_ref, status, t_spawned,
t_returned }` → KG triples `(parent)—spawned→(child)`, `(child)—actedOnBehalfOf→
(parent)`, `(output)—wasGeneratedBy→(task)`, each `[t_spawned,t_returned)`.

**Identity, reframed (operator ruling):** ephemeral spirits are **nameless #has-
stack entities with pet-names** — recall rides **semantic search over the verbatim**
(capabilities live in the content), so a `#has` tag is optional enrichment, never a
deterministic gate. Persistent named actors keep proper-name wings.

**Standards anchor:** W3C Trace Context (correlation) · W3C PROV (edge vocabulary) ·
OTel GenAI (node identity). Stand on the ratified; skip the unfinished OTel
multi-agent spec.

## Layer 4 ~ Ephemeral (what to never keep)

**Capture is ON by default; ephemeral work is LAUNCHED isolated, never gated.**
`lares ephemeral <task>` births a swarm (one-or-more tasked spirits) in a **blind
temp dir outside every harvested path** — ephemeral *by construction*: never mined,
nothing to exclude. The reason: the operator's thousands of blind judge-panel Q&A
flows must leave no trace.

**The keystone — env redirect** (harvester-blindness without a heavy sandbox):

<<~ranks redirect CLAUDE_CONFIG_DIR ~ ~/.claude → $BLIND (run cwd INSIDE $BLIND; guards the #3833 local-.claude leak) -> COPILOT_HOME ~ ~/.copilot (avoid XDG) -> CODEX_HOME ~ ~/.codex -> HOME · XDG_* ~ belt for any missed state dir >>

**Sandbox tiers** (match heaviness to trust): T0 blind-dir+caps (default, trusted
self-judging) → T1 bubblewrap (--ro-bind repo · --tmpfs · --unshare-net) → T2
container → T3 microVM (untrusted code). **Blast-radius:** systemd-run scope caps
(mem/cpu/wall + orphan-reap), credential isolation (inject only the model key).
**Disposal:** `--cleanup` opt-in (OFF by default — the dir PERSISTS for inspection;
tmpfs is the never-touch-disk option). Depth: `agent-provenance#ephemeral-hardening`.
